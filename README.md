# ROMbug Earth

A network-intelligence browser with a built-in VPN tunnel.

**Version 6.31** — Windows

## Install

Download `ROMbugEarth_Setup.exe` from [Releases](https://github.com/ROMbug-developer/rombugearth/releases) and run it.

Installs to a folder of your choosing. Creates Start Menu and Desktop
shortcuts, and registers an uninstaller in Add/Remove Programs.
No administrator rights required. About 600 MB.
